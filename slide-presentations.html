Accessible Slide Presentations

Guidance for creating accessible digital slide presentations.

Overview

Ensuring that digital slides are accessible is essential for creating an inclusive learning environment where all students, including those with disabilities, can fully engage with course content. Thoughtful slide design not only removes barriers to learning but also reflects a commitment to equity, academic success, and respect for diverse learning needs.

Review the following practices that support digital accessibility for your slides:

  • Use High-Contrast Colors: Ensure strong contrast between text and background to support students with low vision or color blindness.
  • Readable Fonts: Choose sans-serif fonts (e.g., Arial, Calibri) and keep font sizes large enough (minimum 18pt).
  • Slide Titles: Provide a unique title on each slide to aid screen reader navigation. Use “1 or 2” and “2 of 2” for topics that span multiple slides.
  • Alt Text for Images: Add clear, concise alternative text for all images, charts, and diagrams.
  • Descriptive Links: Use meaningful link text (e.g., “Read more about accessible design” instead of “Click here”).
  • Reading Order: Check that the slide content follows a logical reading order, especially when using complex layouts.
  • Provide Digital Copies: Share accessible versions (e.g., tagged PDFs or accessible PowerPoint files) ahead of time so students can review content with their preferred tools.
  • Avoid flashing elements: Flashing elements and animations can be distracting and also potentially dangerous for individuals with epilepsy or other disabilities.

How to Make Slide Presentations More Accessible

Microsoft PowerPoint

Video on Reading Order

In this video tutorial, you will learn how to ensure the correct reading order so screen readers navigate through slides in the order that you intend. Reading order is one component of making presentations accessible.

For creating digitally accessible presentations, PowerPoint is easier to use overall and therefore is recommended over Google Slides. It provides more robust features and has a built-in accessibility checker. Review the following guidance to learn how to make your PowerPoint presentations accessible to people with disabilities.

Google Slides

If you prefer to use Google Slides, note that you will need to take some extra steps to ensure accessibility. The following guidance will walk you through different features of Google Slides.

Note: For the guidance below, sequences separated by the > symbol indicate the path to follow in the menu bar. For example, File > Blank Document means select on the File menu, then select Blank Document.

Additional guidance from Google is also available: Google Slides: Make your document, presentation, sheets & videos more accessible

Understanding templates and layouts

If you have been provided with an accessible template for Google Slides, open it and begin adding content. If you are not using an accessible template provided to you, use the default theme or select a new theme from the options provided in Google Slides. If you want to import a theme from outside of the standard Google options, you can do so but may need to take extra steps to ensure reading order and other elements are accessible.

Use the “layouts” for each new slide, rather than adding text boxes or other elements manually. This will ensure that each slide has the correct reading order and you will not need to adjust the reading order of new slides you create.

Add your first slide by selecting Slide > Apply Layout > Title Slide. For your first slide, you must always choose "Title Slide" as the layout. Note: Google Slides does not use headings. Instead it uses slide titles. For subsequent slides: Slide > Apply Layout > Choose the type of layout you need. Do not insert text boxes into slides (select a different layout instead), as this will change the reading order of the slide.

A few additional recommendations to ensure accessibility:

  • If the text color in the theme is not black, change it to black to increase contrast.
  • Use Arial font as a best practice. Avoid serif fonts.
  • Use font size of 40 pt for titles, and minimum of 28 pt for body text.
Titles of Slides

Each slide must have a unique and descriptive title. If content spans multiple slides, add “1 of 2”, “2 of 2” after the title. This makes it clear that the slides are in the correct order and that the topic is continuing across multiple slides.

Adding Images, Alt Text, and Long Descriptions

When adding images, insert the image file rather than copy-pasting images (Insert > Image). Every image must have alt text that describes the image, even if it is decorative or one requiring a long description. To add alt text, select the image and then right click. Select “alt text”.

For decorative images you can write: alt="". This informs the screenreader that this image can be skipped.

Long descriptions are used in addition to alt text when a more detailed description is needed in order to make content understandable. Content that always needs long descriptions are data visualizations and maps. To write a long description use the alt text field to write the location of the long description. For example: “Long description located beneath the chart”. Or you can provide the direct link to a long description. This may link to a google doc, website page, or other document that provides a longer description for those who need it.

View our guide on alternate text for additional information on alternate text.

Creating Lists

Find the list options in “Format > Bullets & Numbering”.

Do not add a manual text box, select a different slide layout if needed. Use only the default bullet points. Do not substitute images, icons, or dashes for bullet points.

Creating Columns

Slide > Apply layout > Select a layout that contains columns.

Do not use text boxes to add columns, select a different slide layout if needed. After adding your content, tab through your content (use tab key) to be sure that elements are read from left to right and top to bottom for keyboard only users.

Creating a Table

Insert > Table > Choose the number of rows and columns you would like for your table.

Tables in Google Slides do not contain header rows and thus are difficult to make accessible as compared with Microsoft products that allow for headers. If you are creating a table, keep it as simple as possible. A more complex table could be added instead as a screenshot with clear descriptive text or long description.

Check your table for accessibility: Put your cursor in the top left cell of your table and tab through to each cell. The order must go from left to right and top to bottom.

Adding Links

To insert a link you can either go to Insert > Link, or type the descriptive name for your link, highlight it and then right click to add the URL for the link. Select apply.

Note: Links must be given names that describe either their destination, or purpose. Do not use "Click Here". View our guide on descriptive links to learn more.

Font Styling

Assistive technologies can not interpret font styling such as bold, italics, and underlining, so your content should not rely on visual styling alone. To emphasize importance without using font styling alone, use “Note:” or “Important:”.

Formatting Multiple Languages in One Document

Select the text that is written in a different language.

Review > Language > Set proofing language > Select the appropriate language > Select OK.

Note: You do not have to set a language for proper names, technical terms, or foreign words that have become a part of common English usage.

Headers, Footers, and Watermarks

Screen readers do not automatically read information contained in these elements, so this information must be duplicated in another location. You can additionally include an introductory and/or appendix slide with this information.

Embedding Audio, Video, and Multimedia Files

For audio only files: provide a transcript (an exact text version of what is being said in the audio file).

For multimedia and video files: provide captions. Audio description is required if visual information is not conveyed in the audio. Transcripts are highly recommended. Note that videos uploaded to Bruin Learn course sites will have captions and transcripts available to instructors.

Checking Accessibility

The easiest way to check accessibility in Google Slides is to use an extension called Grackle. You can install Grackle and use it to check for accessibility issues. You can also export your slides as a PowerPoint (PPT) file and use Microsoft’s accessibility checker. We do not recommend exporting your slides as a PDF, as this will cause accessibility issues that you will need to address manually, such as tagging your document and reading order. Instead, provide students a copy in either Google Slides (you can create a “view only” version) or as a PowerPoint file.

Summary and Key Takeaways

  • Use an accessible template, the default theme, or built-in themes. Use layouts instead of manually creating slide elements.
  • Provide alternative text: Ensure all images include alt text.
  • Build simple, logical tables: Limit tables to standard row/column layouts—never merge, split, or nest cells. Verify reading order by using the Tab key to move sequentially from the top-left to the bottom-right cell.
  • Never rely solely on visual cues: Color, size, shape, or font styling (bold/italics) should never be the only way meaning is conveyed. Always supplement visual indicators with explicit written text (e.g., "Status: Complete" or "Note:").
  • Use descriptive links: Avoid generic text like "Click Here."
  • Duplicate invisible content: Screen readers do not automatically read headers, footers, or watermarks. Crucial information placed in these areas must be repeated in the main document body.
