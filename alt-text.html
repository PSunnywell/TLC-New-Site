How to Write Great Alt Text

Learn how to write effective alternative text and long descriptions for images and other visual content.

Overview

Images can be powerful teaching tools. Photographs, diagrams, charts, graphs, screenshots, illustrations, and other visuals can explain concepts, reinforce ideas, and communicate information more efficiently than text alone.

However, visual information can create a barrier when the meaning of an image is not available to someone who cannot see it. Assistive technologies cannot automatically infer the instructional meaning of graphical objects such as images, images of text, shapes, graphs, and charts.

Who else uses alt text?

  • Search Engine Crawlers (SEO): Bots from Google and other engines read alt text to index images and understand page context, helping the page rank higher in image and web searches.
  • Users with Slow Internet: People in low-bandwidth areas or with disabled image settings see alt text display in place of broken or unloaded images.
  • People with Cognitive Disabilities: Users who process information better through text than complex visuals rely on alt text for clear context.
  • Low-Vision Magnifier Users: People using screen magnification tools read alt text when high zoom levels make fine image details blurry or hard to resolve.
  • AI and Digital Assistants: Voice assistants and AI tools pull alt text data to describe visual elements or feed technical datasets.

In this module, you will learn how to make images more accessible by first considering the purpose of the image in its instructional context. You will learn to distinguish between decorative, informative, and complex images; write meaningful alternative text (alt text); and determine when a complex visual requires a long description.

The goal is not simply to add alt text to every image. It is to provide students with the information they need to understand the purpose and meaning of visual content.

Learning Objectives

By the end of this module, you should be able to:

  • Determine an image's purpose within the context in which it is used.
  • Write effective alternative text for instructional images.
  • Identify when an image requires a long description in addition to alt text.
  • Write an appropriate text alternative for a complex image.
  • Consider color contrast and reading order when incorporating images into digital materials.

How to Create Accessible Images

Provide Alt Text for Images

Images can communicate important information—but that information may not be available to someone who cannot see the image.

Alternative text, or alt text, provides a text alternative that communicates the purpose or meaning of a visual object.

Good alt text depends on context.

Before writing alt text, ask: Why did I include this image?

Then ask: What does a student need to know about it to understand the point I am making?

The alt text should communicate the purpose and/or function of the object.

Avoid unnecessary phrases

You generally do not need to begin alt text with "Image of..." Assistive technology already communicates that the object is an image. However, identifying something specifically as a photo may sometimes provide meaningful context.

Images of text

If an image contains text that students need to read, that information also needs to be accessible. The source presentation instructs content creators to provide the text represented in an image of text as its text alternative.

Whenever possible, however, consider whether the information could be presented as actual text rather than as an image of text.

Logos

Logos should also have appropriate alt text. The presentation recommends identifying the brand or organization name represented by the logo.

What About an Image That You Added for Decoration?

If a visually impaired user would not gain any information relevant for your course by reading an alt text description, then it must be labelled as decorative.

In Bruin Learn, check the "decorative" box located under the alternative text field. The code in HTML will show as alt="".

In Google Slides and Docs, you will need to type alt="" in the alt text description field.

In Microsoft Word and PowerPoint, check the "mark as decorative" box.

When Alt Text Isn't Enough: Long Descriptions

Some visuals contain too much meaningful information to communicate effectively through alt text alone.

Examples may include:

  • Complex charts
  • Graphs
  • Maps
  • Scientific diagrams
  • Infographics
  • Detailed illustrations

In these cases, provide a long description in addition to appropriate alt text.

A long description gives the learner enough information to understand the meaning or purpose of a complex visual. Use the alt text field to tell the user where the long description can be found—for example, beneath the chart—or provide access to the description in another document or webpage.

Think about the instructional purpose

What would I explain verbally if a student could not see this visual?

For a chart, that might include:

  • What is being measured.
  • The variables or categories being compared.
  • Important values.
  • Major trends or patterns.
  • Significant differences.
  • The conclusion students should draw from the visualization.

This approach keeps the description focused on the instructional meaning of the visual.

What Else Needs Alt Text?

What About Buttons?

When using alternative text for buttons, the alt text should describe the action or function of the button, not what it looks like.

  • Don’t start your alt text with "Button".
  • Use clear phrases such as: "Search This Page", "Save Your Document", "Print This Page".

To create a button, you will use the "Create Icon" tool. In the name field, describe what the item is. For example: submit button. The alt text and written text field in this case is the same (Submit). Make sure you are using accessible colors and that the font size is the largest that can fit within the button.

Groups of Images: If multiple images form a single concept or display a concept, write alt text for the group, not for the individual images.

Note: If images have been grouped together for a formatting purpose, ungroup the objects and write alt text for each. Also, there is no alt text field for grouped images in Google Slides, so grouping of images should not be used.

Headshots

  • Prioritize identity and role of the person in the headshot. Knowing who the person is and what they do is most important.
  • Write no more than three short sentences.
  • If the background or attire adds necessary information to the context, include it. For example: Instructor is wearing a lab coat in their science lab.

An example of a simple alt text for a headshot: Petunia Sunnywell, Digital Accessibility Specialist, presenting at a conference.

Race, Age, Gender, Disability

Describe race, age, gender and disability only if it's relevant to the image, or if people in the image have confirmed their identity and want it known. Be careful not to guess someone's race, ethnicity, gender identity, or pronouns based only on appearance. Instead, describe observable information or use identities that are explicitly established by the source.

Mention age when relevant. If exact age is unknown, use general descriptions such as "child", "teen", "older adult", etc.

Physical Appearance

Describe physical appearances when they help communicate the image's meaning. This can include: physique, clothing, hair, facial expression, etc.

Emotions

Don't interpret emotions. Be objective unless you know the emotion for sure. Example: Don't say "They are happy". Instead say "They are smiling".

Key Takeaways

When creating and using images in your course materials, remember:

  • You must determine the context of the image in order to write alt text.
  • Assistive technologies cannot automatically determine the instructional meaning of images, charts, graphs, shapes, or other graphical objects.
  • Alt text should communicate the purpose and/or function of an image, rather than simply describing everything that is visible.
  • Avoid beginning alt text with “image of...” unless identifying the type of image provides meaningful information.
  • Images containing meaningful text need an appropriate text alternative, and logos should identify the brand or organization.
  • Complex images—such as charts, graphs, diagrams, and other detailed visuals—may require a long description in addition to alt text so that their meaning can be fully understood.
  • When a long description is provided elsewhere, make sure the user knows where to find it.
  • Consider the accessibility of the visual itself by providing sufficient color contrast within the image and between the image and surrounding content.
  • Place images appropriately within the content so they are encountered in a logical reading order.
  • AI cannot determine the context of the image. You must double check alt text written by AI.
